Driver Gamepad

Left Trigger - runs intake when held, stops intake and raises arm when released
Left Bummper - toggles arm position when pressed

Right Bumper - runs both shooters when pressed
Right Trigger - sets both shooter servos to shoot position when held
- resets both servos to hold position when released

Button Y - stops both shooters when pressed

Dpad Up increases pollen shooter speed by 50 rpm
Dpad Down decreases pollen shooter speed by 50 rpm
Dpad Left increases nectar shooter speed by 50 rpm
Dpad Right decreases nectar shooter speed by 50 rpm

Button B - aligns robot to shoot target when pressed. Target is set by robot fiels location
Button X - positions robot to auto shoot position for current robot location
Button A - currently not assigned

Button Back - toggles alliance when pressed - in case of problems
Button Start - resets odometry when pressed - in case of problems both alliance positions are in the 
field corner by the Loading Zone, facing the corner and against both walls.
